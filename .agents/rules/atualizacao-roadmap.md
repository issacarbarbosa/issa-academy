# Regra de Comportamento: Atualização Automática do Roadmap

Esta regra define a obrigação comportamental de manutenção e sincronização contínua do arquivo `ROADMAP.md`.

---

## 📋 Diretriz de Atualização
Sempre que você (agente) **implementar, refatorar código, corrigir bugs ou adicionar novas funcionalidades/testes** nesta sessão, você DEVE atualizar o arquivo físico `ROADMAP.md` na raiz do projeto antes de concluir a tarefa:

1. Avalie o estado dos itens em `ROADMAP.md`.
2. Atualize o status dos itens correspondentes:
   - De `[ ]` (pendente) para `[x]` (concluído) ou `[/]` (parcialmente concluído).
3. Se um novo recurso relevante for concluído, adicione uma entrada concisa na seção de histórico de alterações recentes com a data correspondente.
4. Para consultas puramente informativas ou respostas a perguntas conceituais sem alteração de código, não é necessário modificar o arquivo.
