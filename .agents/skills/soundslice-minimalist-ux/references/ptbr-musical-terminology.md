# Glossário Oficial de Terminologia Musical (Soundslice EN -> PT-BR)

| Termo Original (Prints Soundslice) | Tradução Oficial no SliceScore Studio (`pt-BR`) |
|---|---|
| `Speed` / `Speed training` | `Velocidade` / `Treino de velocidade` |
| `Initial speed` / `Final speed` | `Velocidade inicial` / `Velocidade final` |
| `Increase by...` | `Aumentar em...` |
| `Metronome` | `Metrônomo` |
| `On every beat` / `On first beat` / `Subdivision` | `Em cada tempo` / `Apenas no 1º tempo` / `Subdivisão (colcheias)` |
| `Count-in` | `Contagem regressiva` |
| `Always` / `At start only` / `With loop only` | `Sempre` / `Apenas no início` / `Apenas em loops` |
| `1 bar long` / `2 bars long` | `1 compasso` / `2 compassos` |
| `Focus` / `Focused on bars: X to Y` | `Foco` / `Focado nos compassos: X até Y` |
| `Customize layout` / `Horizontal notation` | `Personalizar layout` / `Notação horizontal` |
| `Customize notation` / `Pitch names` | `Personalizar notação` / `Nomes das notas (Dó, Ré...)` |
| `Fingering` / `Rhythm counts` | `Dedilhado e arcadas` / `Contagem rítmica (1 2 3 4)` |
| `Bar numbers` / `Every bar` / `Hide` | `Numeração de compassos` / `Cada compasso` / `Ocultar` |
| `Player style` / `Highlight: Bar / Notes` | `Estilo do reprodutor` / `Destacar: Compasso / Notas` |
| `C, D, E, F, F#, G, A, B` | `Dó, Ré, Mi, Fá, Fá♯, Sol, Lá, Si` (com acento agudo obrigatório) |
